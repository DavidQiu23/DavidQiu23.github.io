```bash
git remote -v                 # 查看目前遠端儲存庫設定
git remote add <name> <url>   # 新增遠端儲存庫 (例如 name 為 origin)
git push <name> <branch_name> # 將本地分支推送到遠端
git pull                      # 拉取遠端資料並自動合併
```

## 強制覆蓋遠端分支

當本地歷史（例如 rebase、amend 後）與遠端分歧，需要用本地覆寫遠端時：

```bash
# 強制推送，直接以本地覆蓋遠端分支
git push <name> <branch_name> --force

# 較安全的做法：只有在遠端與你上次取得的狀態一致時才覆蓋，
# 避免蓋掉他人剛推上去的 commit
git push <name> <branch_name> --force-with-lease
```

> 強制推送會改寫遠端歷史，共用分支請務必先與團隊確認，優先使用 `--force-with-lease`。
