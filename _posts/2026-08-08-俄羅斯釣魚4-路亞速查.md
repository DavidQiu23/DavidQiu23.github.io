## 通用設定

### 收線速度

**按住 `R` 鍵，用滾輪或 `-` / `+` 調整收線速度。** 回鍋第一件事就是把這個調對，其他都是其次。

| 竿種 | 收線速度 |
| --- | --- |
| 飛德桿 | 開到最高 |
| 路亞桿 | 看地圖和餌，見下方各地圖 |

### 摩擦

| 竿種 | 摩擦 |
| --- | --- |
| 飛德桿 | 卡 29（＝刻度上限，拉滿） |
| 路亞桿 | 別拉滿，15 ~ 20 起手 |

{: .notice--warning}
> **路亞不要卡 29。** 摩擦拉滿等於不洩力，大魚一衝就是當場斷線或斷竿。飛德桿卡滿是因為那是另一種玩法，別把習慣帶過去。

遛魚時看負載條，滾輪隨時調摩擦，讓指示維持在黃區、不要進紅區。

### 配裝強度順序

> **竿 > 輪子 > 線**

竿最強、輪子次之、線最弱。

原因在負載條的機制：**那條顯示的是整組裝備中「最弱一環」的負載，滿到紅色時，斷的就是最弱的那一環。** 既然一定有一環會斷，就要刻意讓它是線——線最便宜、最好換。

反過來配（線比輪子硬）就會變成爆輪或斷竿，修起來貴得多。

## 白河（Belaya River）

12 級解鎖，白河套大約 800 銀。打亮片，勻收。

### 餌

| 型號 | 備註 |
| --- | --- |
| **2018** | 亮片 |
| **004** | 旋轉亮片，8 號鉤 + 紅毛 |

備選：旋轉 01、Dragonbell 2-002（帶毛鉤的版本）、Syberia Dragonfly Original 01-007 ~ 03-007。

### 收線

| 項目 | 設定 |
| --- | --- |
| 收線速度 | 16 ~ 25，實戰多在 **18 ~ 23**，起手 **22** |
| 操作 | 按住收線一路收回來，不用抽停也不用變速 |

沒口的時候先在區間內微調速度，不要急著改手法。

### 點位

72:61、71:37、73:49、72:60、72:62

## 廓里湖（Kuori Lake）

16 級解鎖，主打路亞。打魚型餌，搐動。

### 餌

| 型號 | 備註 |
| --- | --- |
| **F11004 / F11006** | 魚型餌 |

### 收線

| 項目 | 設定 |
| --- | --- |
| 收線速度 | **50** |
| 操作 | 按住 `Shift`（加速收線），**點一秒、放一秒** 反覆 |

### 注意

狗魚口集中在湖邊草邊。引線還沒定論：最高級的氟碳照樣會被咬斷。

## 排查

| 症狀 | 怎麼辦 |
| --- | --- |
| 完全沒口 | 先換餌，換過還是沒口就換點 |
| 只上梅花鱸或連續幾竿空 | 換點 |
| 常常斷線 | 檢查摩擦是不是設太緊、線有沒有磨損 |
| 爆輪或斷竿 | 配裝順序錯了，線配得比輪子還硬 |
