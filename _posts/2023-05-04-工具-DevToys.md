[DevToys](https://devtoys.app/) 是一款免費開源的桌面工具箱，把開發常用的小工具整合在一起，所有處理都在本機離線完成，兼顧隱私。

## 主要特色

- **30+ 內建工具**：JSON/YAML 轉換、Base64、進位轉換、JWT 解碼、雜湊 / UUID / 密碼產生器、JSON / SQL / XML 格式化、正則表達式測試等。
- **Smart Detection**：自動偵測剪貼簿內容，推薦最適合的工具。
- **跨平台**：支援 Windows / macOS / Linux，內建深色 / 淺色主題與子母畫面模式。
- **可擴充**：社群可透過 NuGet 貢獻工具，也能用官方 SDK 自製工具。
- **CLI 版本**：可整合進 CI 流程或終端機工作流。
