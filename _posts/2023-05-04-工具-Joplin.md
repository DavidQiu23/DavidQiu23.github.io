[Joplin](https://joplinapp.org/) 是一款免費開源、注重隱私的筆記軟體，支援 Markdown 語法，可作為 Notion 或 Evernote 的優秀替代品。

## 主要特色

- **多格式筆記**：除了文字，也支援圖片、影片、PDF、音訊、數學式與圖表。
- **端對端加密 (E2EE)**：筆記以開放格式儲存，加密後只有自己能存取。
- **跨平台同步**：支援 Windows / macOS / Linux / Android / iOS，可透過 Joplin Cloud、Dropbox、OneDrive 等服務同步。
- **Web Clipper**：Chrome / Firefox 擴充套件，可直接把網頁或截圖存成筆記。
- **可擴充**：提供外掛、自訂主題、Rich Text 與 Markdown 兩種編輯器，以及擴充 API。
