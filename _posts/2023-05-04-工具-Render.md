[Render](https://render.com/) 是一站式的雲端託管平台，主打「The cloud for builders」，非常適合部署個人專案或靜態網站。

## 主要特色

- **多種服務型態**：靜態網站、Web Service、背景 Worker、Cron Job、託管 PostgreSQL 與 Key-Value 儲存。
- **從 Git 自動部署**：連結儲存庫後可自動部署，支援零停機部署與 preview 環境。
- **開發者友善**：自動 HTTPS / SSL、自動擴展、私有網路、持久化磁碟。
- **多元整合**：提供 CLI、REST API 與 Docker 支援，方便自動化部署。
