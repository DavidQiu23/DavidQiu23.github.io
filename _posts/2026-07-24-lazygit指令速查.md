[lazygit](https://github.com/jesseduffield/lazygit) 是用 Go 寫的終端機 Git 介面 (TUI)，把 stage、commit、分支、rebase 全部濃縮成鍵盤操作，不用離開終端機。這篇速查安裝方式與最常用的按鍵。

## 安裝

```bash
# macOS
brew install lazygit

# Windows (Scoop)
scoop bucket add extras
scoop install lazygit
# 或 winget
winget install -e --id=JesseDuffield.lazygit

# Ubuntu 25.10 以後：套件庫已內建
sudo apt install lazygit

# Ubuntu 25.04 及更早：下載官方 release 執行檔
LAZYGIT_VERSION=$(curl -s "https://api.github.com/repos/jesseduffield/lazygit/releases/latest" | grep -Po '"tag_name": *"v\K[^"]*')
LAZYGIT_ARCH=$(uname -m | sed -e 's/aarch64/arm64/')
curl -Lo lazygit.tar.gz "https://github.com/jesseduffield/lazygit/releases/download/v${LAZYGIT_VERSION}/lazygit_${LAZYGIT_VERSION}_Linux_${LAZYGIT_ARCH}.tar.gz"
tar xf lazygit.tar.gz lazygit
sudo install lazygit -D -t /usr/local/bin/
```

在任一 Git 專案目錄下輸入 `lazygit` 即可開啟。忘記按鍵時，按 `?` 會列出當下可用的所有操作。

## 常用按鍵

### 切換與瀏覽

| 按鍵 | 作用 |
| --- | --- |
| `1`~`5` | 切換面板 (Status / Files / Branches / Commits / Stash) |
| `j` / `k` | 上下移動 |
| `Enter` | 進入選取項目看細節 |
| `?` | 顯示當下所有快捷鍵 |
| `q` | 退出 |

### Stage 與 Commit（Files 面板 `2`）

| 按鍵 | 作用 |
| --- | --- |
| `Space` | stage / unstage 選取檔案 |
| `a` | stage 全部 |
| `c` | 輸入 commit 訊息並送出 |
| `C` | 開啟編輯器寫較長訊息 |
| `s` | 把目前變更收進 stash |
| `Ctrl+s` | 依選取檔案路徑過濾 commit log（查看單檔歷史） |

選檔案按 `Ctrl+s` 以該檔路徑過濾，Commits 面板 (`4`) 只列出動過這個檔案的 commit（＝單檔 log）；再按一次 `Ctrl+s` 清除過濾。

### 分支（Branches 面板 `3`）

| 按鍵 | 作用 |
| --- | --- |
| `Space` | checkout 選取分支 |
| `n` | 新增分支 |
| `d` | 刪除分支 |
| `M` | 合併進當前分支 |
| `r` | rebase |

### 推送與拉取

| 按鍵 | 作用 |
| --- | --- |
| `p` | pull |
| `P` | push |

### 互動式 Rebase（Commits 面板 `4`）

| 按鍵 | 作用 |
| --- | --- |
| `s` | squash（合併進上一個 commit） |
| `f` | fixup（合併但捨棄訊息） |
| `d` | drop（刪除 commit） |
| `Ctrl+j` / `Ctrl+k` | 調整 commit 順序 |
